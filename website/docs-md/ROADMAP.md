# OFFPEAK roadmap

**Live** means shipped and usable today. Everything else is planned, in the phase order set by the OFFPEAK product documents. No dates are set. Each phase launches only when its gates pass.

## Live now
- **Product preview website.** Explains the product, the off-peak pricing model and the research behind it.
- **Official X account, [@UseOffPeak](https://x.com/UseOffPeak).** Project updates.

## Next (P1: endpoint and pricing)
- **One endpoint.** An OpenAI-compatible API for open-weight models: chat with streaming, tools and JSON mode, plus embeddings. Swap the base URL and keep your code.
- **Off-peak pricing.** Hosts post 168 hourly prices, and router-measured load moves live prices from 0.4× to 1.2× of them.
- **Withdrawable balance.** Prepaid USDG in a vault that you can withdraw from at any time. Withdraw-all completes within 2 hours.
- **Proof, not claims.** Signed usage records on every response, hourly Merkle roots on Robinhood Chain, and bonded, audited hosts.
- **Launch models.** 3 open-weight models on studio-run GPU hosts, with the first outside hosts in probation.
- **Mainnet contracts.** Deployed on Robinhood Chain after an external audit, with a 500 USDG per-buyer beta deposit cap.

## Later
- **P2, keyless agent payments.** x402 with payment channels first and `upto` as the fallback, so an agent pays per call with no key.
- **P2, night jobs.** Mark a job flexible with a deadline, lock the price up front, and run it in a cheap hour.
- **P2, MCP tools.** Complete, price, schedule and usage tools for agents.
- **P3, Windows.** Tradable reservations of future capacity, sold by falling-price auction and resold for 1% + 10% of markup.
- **P3, sealed hosts.** Attested confidential hardware with client-side encryption, so neither the host operator nor OFFPEAK can read prompts.
- **P3, audits at scale.** Model-swap audits across more hosts and GPU classes.
- **$OFPK utility.** Fee tiers, extra host bond weight and early Window access, switched on after legal review.
