CURRENT HERO: FRONT-FACING LIVE CITY

Regenerate the current transparent SVG, state, poster, visual proof and validation:
  node render-city.mjs --live

The original --render path remains available for the earlier isometric video.

The live scene uses a 1600 x 700 viewbox and horizontal facades:
  screenX = 800 + 2.25 * x - 0.2 * y
  screenY = 435 + 0.9 * y - 1.35 * z

Projection constants are exported in offpeak-city-live-state.json. The browser
runtime consumes that camera, including vertical scale and dynamic actor origins.
The six districts retain 19 fans, 41 LEDs, robot eyes, model workshops, gate arms,
printers, traffic, drone couriers, token conveyors and pointer-responsive fields.

Three shallow graphite instruments sit along the city's front edge. Their labels
and values are responsive HTML over the authored SVG frames. Selecting a district
changes the metric set and sparkline data. These are explicitly illustrative:
18 example metrics, generated locally, updated once per second, with a 20-second
period. No external data feed or promised commercial rates are represented.

Mount contract:
  <div data-city-host></div>
  /assets/city-interactive.css
  /assets/city-interactive.js (defer; auto-mounts)

State: data-city-view=front, data-city-analytics=illustrative,
data-city-selected, data-city-metric-set, data-city-paused, data-city-time.
API: host._offpeakCity.select(id), pause(), play(), getState(), destroy().

Desktop intentionally permits horizontal edge overflow. The SVG uses
preserveAspectRatio=none so the runtime's buttons and responsive text follow the
exact resized viewport. Mobile uses native horizontal city panning and six
always-visible district tabs. Reduced motion starts paused; offscreen and hidden
tabs pause the simulation. The footer describes selection and provides pause.

Verification is recorded in live-validation.json. Current source 0s and 20s render
to identical RGBA bytes; the image has no opaque background or enclosing slab.
city-live-proof.png is flattened on #f8f8f8 for review only. The deployed poster
offpeak-city-live-poster.png preserves transparency.
