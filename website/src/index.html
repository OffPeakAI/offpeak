OFFPEAK for developers

An explicit flow from the first quote to the final receipt.

Built for work like yours.

Questions

OFFPEAK is being built for open-model text inference on spare GPU capacity: extraction, classification, summarization, and other repeatable work. This site is a product preview.

Proposed prices respond to available serving capacity, subject to a measured cost floor. More spare capacity can lower a quote; discounts are not guaranteed. Inspect both rates and the maximum charge before authorizing.

The website is a free preview, and any example values on it are illustrative. Paid inference and final commercial terms are still in development. The initial design uses usage-based prepaid balances, not a subscription plan.

The planned pilot uses your wallet to authorize each request, so there is no OFFPEAK-issued inference API key. Your wallet key remains a credential. Delegated budgets and direct x402 payments are later work.

Each quote fixes the prompt, model, rates, and output ceiling. You authorize a maximum charge. A successful request pays for measured usage, and the unused reserve is released. Failed pilot requests are unbilled.

Initial scope is one approved open-weight model revision, one region, and non-streaming text requests. The model, licensing, quality, and serving rates must be validated before paid access. Streaming, tools, and broader supply are future scope.

The planned pilot returns available, unreserved paid balances to the same wallet, token, and network. OFFPEAK controls the prepaid treasury and processes withdrawals. Pending transfers and reserved funds remain separate.

It checks that OFFPEAK signed a particular billing record and included it in a committed batch. It does not independently prove that a GPU performed the work, that metering was truthful, or that the model answer is correct.

The workflow gallery offers eighteen illustrative starting points for classification, extraction, summarization, and review. Read the docs to see how quotes, caps and usage records are designed to work; no wallet, funds, or live model is connected.
