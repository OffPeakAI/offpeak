# Stuck channel close

`ChannelManager` is a P2 contract and is not deployed yet. This page applies once it is.

The keeper must land the latest voucher before `challengeEndsAt`. `channel_close_margin_seconds` below 1,800 pages.

1. **Check the keeper's gas balance** and the `channel-close-watch` job.
2. **Submit by hand if needed:** `settleChannel` accepts the keeper or the payee, using the voucher in `shared.channel_state`.
3. **A missed window loses only the unclaimed amount,** and the host is paid from the protocol reserve through the normal write-off.
